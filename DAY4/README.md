# Task Manager

A beginner-friendly command-line Task Manager built using Python, PostgreSQL, psycopg2, and Object-Oriented Programming.

## Features

- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Complete tasks
- Assign categories to tasks
- View tasks by category
- Category summary
- GROUP BY and HAVING reports
- JSON export
- Logging
- Runtime error handling
- PostgreSQL persistence
- Unit testing

## Technologies Used

- Python
- PostgreSQL
- psycopg2
- SQL
- Object-Oriented Programming
- JSON
- unittest
- Git
- GitHub
